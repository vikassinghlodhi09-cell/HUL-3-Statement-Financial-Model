# HUL Standalone 3-Statement Financial Model

## Project Overview

Built an integrated three-statement financial model for Hindustan Unilever Limited (HUL), linking the Income Statement, Balance Sheet and Cash Flow Statement to analyze historical performance and project future financials.

## Model Coverage

- Historical financials: FY2021–FY2026
- Forecast period: FY2027E–FY2030E
- Currency: ₹ crore
- Standalone financial model

## Key Components

- Income Statement
- Balance Sheet
- Cash Flow Statement
- Financial Assumptions
- Financial Ratio Analysis
- Financial Dashboard
- Historical vs. Forecast Analysis

## Forecasting Approach

Key operating assumptions are derived from historical performance, including:

- Revenue growth
- Cost of goods sold as % of revenue
- Employee cost as % of revenue
- Other expenses as % of revenue
- Depreciation as % of revenue
- Effective tax rate
- Working capital assumptions

## Key Financial Ratios

- Net Profit Margin
- Gross Margin
- Operating Margin
- ROE
- Current Ratio
- Quick Ratio
- Cash Conversion Cycle
- Debt-to-Equity

## Model Structure

1. Dashboard
2. Income Statement
3. Balance Sheet
4. Cash Flow Statement
5. Assumptions
6. Projected Financial Statements
7. Financial Ratios
